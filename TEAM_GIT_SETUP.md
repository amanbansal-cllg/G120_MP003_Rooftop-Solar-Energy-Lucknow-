# Team Git identity setup

This repository is currently configured locally for the initial commit by
Arpit Kumar. Each teammate must configure their own cloned working copy before
creating their own commits.

## Arpit Kumar

```powershell
git config --local user.name "Arpit Kumar"
git config --local user.email "arpitarnav2005@gmail.com"
```

Verify before committing:

```powershell
git config --local --get user.name
git config --local --get user.email
```

Use the email address connected to the member's GitHub account so the commit is
credited to the correct account.
